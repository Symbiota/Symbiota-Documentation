**Extended data** in Symbiota portals is data provided beyond the core "occurrence" (i.e., taxonomy, locality, collector) data, such as links to external resources, material samples, links between records/occurrences, and links to images. Extended data often has a _one-to-many_ relationship with occurrence data, meaning that a single occurrence record can be associated with multiple extended data entries or links.

The Extended Data Importer tool can be used to import several different types of data:
* [Associations](/Collection_Manager_Guide/Importing_Uploading/linked_resources)
* [Determinations](/Portal_Manager_Guide/importing_determinations) (historical only; _currently only available to superadministrators_)
* [Media/Image URLs](/Collection_Manager_Guide/Images/media_upload_url)
* Identifiers (e.g., accession numbers)
* [Material samples](/Collection_Manager_Guide/Importing_Uploading/material_samples) (_only if the material sample module is turned on for your collection_)

Click the extended data type you wish to upload to view its instructions.
