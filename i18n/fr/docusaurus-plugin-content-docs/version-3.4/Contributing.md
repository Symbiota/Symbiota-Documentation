Symbiota Docs est une initiative collaborative de la communauté Symbiota, coordonnée par le Symbiota Support Hub. Nous accueillons et encourageons toutes les contributions.

### À quoi puis-je contribuer ?

- Correction d'erreurs mineures (fautes d'orthographe, problèmes de mise en forme, signalement de liens rompus)
- Relecture du contenu existant
- Création de nouveau contenu ou enrichissement du contenu existant
- Traduction de contenu
- Signalement de bugs
- Suggestions de contenu

### Comment contribuer

#### Détails techniques (pour les utilisateurs familiers avec GitHub)

Le contenu de ce site est en open source et géré via la plateforme de développement [GitHub](https://github.com/). L'interface est compilée avec... Toute personne disposant d'un compte GitHub peut créer un « fork » (une copie) de ce dépôt et contribuer directement à l'arborescence des dossiers, ou utiliser le bouton « Modifier ce contenu sur GitHub » situé au bas d'une page pour en modifier le contenu dans un nouveau fork. Pour soumettre votre contribution, veuillez [ouvrir une « pull request »](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/creating-a-pull-request). Pour signaler des bugs, veuillez ouvrir une « issue » (ticket) dans notre [dépôt GitHub](https://github.com/Symbiota/Symbiota-Documentation/). Pour consulter les discussions ou en lancer une nouvelle, veuillez visiter l'onglet [Discussions de notre dépôt GitHub](https://github.com/BioKIC/symbiota-docs/discussions).

#### Comment contribuer au contenu directement sur GitHub

1. Créez un compte utilisateur sur [GitHub](https://github.com/signup?ref_cta=Sign+up&ref_loc=header+logged+out&ref_page=%2F&source=header-home).
2. Familiarisez-vous avec le langage [Markdown](https://en.wikipedia.org/wiki/Markdown). Voici un lien vers une excellente [fiche mémo fournie par le Markdown Guide](https://www.markdownguide.org/cheat-sheet/).
3. Apprenez les bases du flux de travail Git sur GitHub : [créer un fork d'un dépôt](https://docs.github.com/en/get-started/quickstart/fork-a-repo), [envoyer des modifications (« push »)](https://docs.github.com/en/get-started/using-git/pushing-commits-to-a-remote-repository) et [ouvrir une « pull request » sur](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/creating-a-pull-request). GitHub](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/creating-a-pull-request).
4. Parcourez les rubriques structurées situées dans le dossier `content` du [dépôt GitHub Symbiota Docs](https://github.com/BioKIC/symbiota-docs).
5. Explorez les options de mise en forme disponibles dans le répertoire `resources/templates`.
6. Facultatif : contactez le [centre d'assistance Symbiota](mailto:help@symbiota.org) pour signaler votre intention de contribuer via GitHub. Nous échangerons avec vous au sujet de vos contributions et répondrons à toutes vos questions éventuelles.

#### Comment contribuer si vous ne souhaitez pas apprendre à utiliser GitHub

Envoyez vos contributions sous forme de documents Word ou texte au [Symbiota Support Hub](mailto:help@symbiota.org). N'oubliez pas d'indiquer votre nom complet afin que nous puissions vous créditer en tant qu'auteur ! Veuillez joindre les images dans des fichiers séparés.
