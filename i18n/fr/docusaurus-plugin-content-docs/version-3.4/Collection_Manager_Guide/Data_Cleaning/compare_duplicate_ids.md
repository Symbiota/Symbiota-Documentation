:::info

Cette page explique comment identifier, dans votre collection, des spécimens dont l'identification (c.-à-d. le nom scientifique) diffère de celle de leurs doubles conservés dans une autre collection.

:::

Accédez à cet outil via le panneau de contrôle d'administration (cliquez sur « Mon profil », puis sur le nom de la collection dans le bloc « Gestion des collections »). Cliquez sur « Outils de nettoyage des doubles ». Dans le bloc inférieur, sous la rubrique « Taxonomie », cliquez sur « Spécimens en double présentant des conflits d'identification potentiels... ».

Cet outil dresse la liste des groupes de spécimens en double (spécimens partageant les mêmes collecteur, numéro et date, même entre différentes collections) pour lesquels un ou plusieurs spécimens ne portent pas le même nom taxonomique. Il permet de repérer les spécimens de votre collection qu'il conviendrait d'annoter avec le nom taxonomique le plus récemment attribué. Par exemple, dans le groupe ci-dessous, OBI et UCR pourraient envisager d'annoter leurs spécimens en fonction de l'identification la plus récente du double conservé au SBBG. Vous pouvez consulter les fiches détaillées de chaque spécimen en cliquant sur le numéro de catalogue correspondant.
