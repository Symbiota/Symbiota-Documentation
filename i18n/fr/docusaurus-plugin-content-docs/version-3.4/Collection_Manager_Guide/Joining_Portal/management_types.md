Il existe deux manières principales pour les collections de présenter leurs données au sein des portails Symbiota : en mode « **en direct** » (live) ou sous forme d'« **instantané** » (snapshot). La méthode de gestion des données utilisée par chaque collection dans Symbiota est indiquée sur son profil, sous la rubrique « Plus d'informations » (« More Information »). Par exemple :

![Exemple de collection gérée « en direct »](/img/managementtype-example2026.png)

Une collection gérée « **en direct** » est une collection dont les données sont administrées directement dans le portail Symbiota. La saisie, la modification et la numérisation des données s'effectuent via un navigateur web, au sein même du portail. Les collections gérées « en direct » peuvent débuter avec un volume de données quelconque ; si la collection dispose déjà de données sous forme de feuille de calcul, de base de données ou d'archive Darwin Core, elle peut les importer dans le portail Symbiota et les y gérer par la suite. Il est également possible d'entamer un processus de numérisation dans le portail sans disposer de données préalables. Parmi les avantages de la gestion « en direct » dans un portail Symbiota, on peut citer :

- La gestion des données via un navigateur web, permettant à plusieurs utilisateurs (disposant des autorisations nécessaires) de travailler à distance.
- L'accès à des outils de numérisation performants, tels que le géoréférencement par lots ou la récupération de données à partir d'enregistrements en double.
- L'accès à des outils de nettoyage des données, notamment pour la taxonomie et la géographie.

Une collection gérée sous forme d'« **instantané** » est une collection dont les données sont administrées dans un système de gestion distinct (par exemple, Specify, Arctos ou FileMaker) ; une copie de ces données est importée dans un portail Symbiota afin de les rendre accessibles à un plus large public et/ou de permettre leur publication vers des agrégateurs mondiaux. Les collections utilisant ce mode peuvent importer leurs données dans un portail Symbiota via une feuille de calcul, une archive Darwin Core, un outil IPT (Integrated Publishing Toolkit) ou tout autre système basé sur le web. Il est possible de configurer et d'enregistrer un profil d'importation qui facilitera les mises à jour ultérieures des données, à condition que l'identifiant unique provenant de la source initiale (appelé « dbpk » dans Symbiota) demeure inchangé entre les différentes importations. Dans les deux cas, les collections présentes sur les portails Symbiota bénéficient des avantages suivants :

- Participation à un réseau doté d’une expertise régionale et/ou taxonomique spécifique
- Assistance pour les requêtes en arrière-plan et la résolution de problèmes au quotidien, via le centre de support Symbiota (Symbiota Support Hub)
- Publication simple et rapide de vos données vers des agrégateurs mondiaux (par ex. le GBIF), si vous le souhaitez
