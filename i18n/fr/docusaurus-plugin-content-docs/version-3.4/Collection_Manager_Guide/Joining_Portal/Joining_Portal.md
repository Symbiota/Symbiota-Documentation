Cliquez sur le bouton ci-dessous pour consulter la liste des portails Symbiota actifs. Choisissez un portail Symbiota correspondant au périmètre de vos données. Vous pouvez intégrer vos données à un portail Symbiota soit sous forme de collection « dynamique » (mise à jour en temps réel), soit sous forme d'« instantané » (copie figée) ; consultez [cette page](/Collection_Manager_Guide/Joining_Portal/management_types) pour plus d'informations sur les modes de gestion dans les portails Symbiota.

Une fois que vous avez identifié le portail Symbiota sur lequel vous souhaitez publier vos données de spécimens, contactez les responsables du projet ou du portail pour devenir fournisseur de données. Les coordonnées des responsables sont généralement indiquées sur la page d'accueil ou dans le menu latéral du portail. Si vous ne parvenez pas à trouver ces informations, veuillez contacter help@symbiota.org.

Il est possible de publier des données sur plusieurs portails ; toutefois, il est recommandé de ne gérer un jeu de données ou une collection spécifique que sur un seul portail Symbiota, les autres portails ne contenant alors qu'un « instantané » (copie) de ces données. Des collections distinctes (par exemple, plantes vasculaires, lichens ou bryophytes) peuvent être gérées de manière dynamique sur leurs portails respectifs.

En règle générale, le responsable du portail aura besoin des informations listées ci-dessous pour intégrer votre collection au portail. Une fois la collection ajoutée, les données pourront être importées. Consultez la page consacrée à l'[importation de données de spécimens](/Collection_Manager_Guide/Importing_Uploading) pour plus de détails sur les méthodes et les formats de données acceptés.

Informations nécessaires pour créer une nouvelle collection au sein d’un portail :

* Titre de la collection, tel qu’il apparaîtra sur la page de recherche
* Codes de l’institution et de la collection (par ex. acronymes)
* Brève description du contenu de la collection et des types de préparation
* Contact(s) : nom, fonction, adresse électronique et identifiant ORCID (si disponible)
* Lien(s) vers la page d’accueil et/ou d’autres ressources externes
* Icône de la collection ou de l’institution : une petite image représentant visuellement la collection (les icônes ayant des dimensions à peu près égales en hauteur et en largeur sont préférables)
* Droits d’utilisation souhaités. Le gestionnaire du portail pourra vous conseiller à ce sujet. Il peut également être utile de consulter les liens suivants relatifs aux licences Creative Commons : https://creativecommons.org/licenses/, http://wiki.creativecommons.org/Data
* Précisez si vous publiez un « instantané » (snapshot) de vos données — qui sera mis à jour périodiquement — ou si vous prévoyez de gérer ces données en tant qu’ensemble dynamique directement au sein du portail
* Source de l’identifiant unique global (GUID) pour les notices de spécimens. Si les notices sont gérées directement dans le portail, nous recommandons de laisser le système générer automatiquement un GUID (UUID) lors de la création de chaque notice. Si un instantané des données est publié à partir d’un système de gestion interne, les GUID doivent être générés localement, puis inclus dans les données transmises au portail.

**Que faire si je dispose de plusieurs collections ou types de données ?**
Si vous gérez plusieurs collections (par exemple, plantes vasculaires, champignons et bryophytes), il est recommandé de les traiter séparément dans leurs portails de données respectifs. En effet, les référentiels taxonomiques de chaque portail sont spécifiquement adaptés au groupe taxonomique concerné ; par ailleurs, vous bénéficierez plus facilement des outils optimisant la numérisation (comme la détection des doublons) au sein du portail dédié. Pour plus d’informations, consultez notre page consacrée à la [gestion de plusieurs portails](/Collection_Manager_Guide/Joining_Portal/management_types).
