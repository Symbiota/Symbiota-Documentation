Les collections qui gèrent leurs données dans Specify 6 peuvent transmettre une copie de celles-ci vers un portail Symbiota en utilisant les outils intégrés à Specify. Les instructions relatives à cette procédure sont disponibles sur le [forum Specify](https://discourse.specifysoftware.org/t/sharing-data-with-symbiota/193).

Les collections qui gèrent leurs données dans Specify 7 peuvent fournir une copie de leurs données via un flux RSS. Veuillez contacter le [support de Specify](mailto:support@specifysoftware.org) pour obtenir plus d'informations sur cette option.
