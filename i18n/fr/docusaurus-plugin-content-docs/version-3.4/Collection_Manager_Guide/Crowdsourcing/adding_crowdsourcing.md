:::info

Cette page explique comment un gestionnaire de collection ou un administrateur peut ajouter des notices de spécimens à la file d'attente pour une transcription participative (crowdsourcing) et comment examiner les transcriptions ainsi obtenues.

:::

:::tip

Un webinaire illustrant ce processus est disponible ici : [https://youtu.be/1IZhUMqCGvs](https://youtu.be/1IZhUMqCGvs)

:::

Les spécimens peuvent être soumis à une transcription participative s'ils (1) disposent d'une image associée et (2) ont un statut de traitement « non traité » (*unprocessed*). Pour gérer le statut de traitement des spécimens, vous pouvez utiliser l'outil d'édition par lots (*Batch Editor Tool*) si nécessaire. Les images de spécimens ajoutées à un portail sans données associées se voient automatiquement attribuer le statut « non traité » ; toutefois, si des données minimales ont été importées avec les images, le statut de traitement a été défini par la personne ayant effectué l'importation.

1. Accédez à votre panneau de contrôle d'administration (cliquez sur « Mon profil », puis sur le nom de la collection dans le bloc « Gestion de la collection »).
2. Dans le panneau de contrôle d'administration, cliquez sur « Boîte à outils de traitement » (*Processing Toolbox*).
3. Cliquez sur l'onglet « Crowdsourcing ».

:::note

Vous ne voyez pas d'onglet « Crowdsourcing » ? Il est possible que cette fonctionnalité ne soit pas activée sur votre portail. Contactez l'administrateur de votre portail pour plus d'informations.

:::

4. Sur la page qui s'affiche, vous verrez le décompte des notices présentes dans la file d'attente, de celles qui ont été traitées et de celles qui pourraient être ajoutées à la file. Cliquez sur le bouton « Ajouter à la file d'attente » (*Add to Queue*) pour accéder à des options supplémentaires permettant d'affiner la sélection des spécimens à inclure (voir la capture d'écran ci-dessous).

![Ajouter des spécimens à la file d'attente de crowdsourcing](/img/crowdsourcing2_2026.png)

:::tip

Il est impossible de rechercher des valeurs qui n'existent pas ! De nombreux enregistrements « non traités » ne contiennent aucune donnée dans les champs ; par conséquent, ils risquent de ne pas être inclus si vous restreignez votre recherche à l'un des champs supplémentaires indiqués ci-dessus.

:::

5. Définissez le nombre de spécimens à ajouter simultanément à la file d'attente en modifiant la valeur du champ « Limite d'enregistrements » (Record Limit). 
- Il est déconseillé d'ajouter plusieurs milliers d'enregistrements à la fois. Une quantité excessive d'enregistrements pourrait décourager les participants au crowdsourcing et leur donner l'impression qu'ils ne parviendront jamais à terminer la tâche !
6. Cliquez sur le bouton « Ajouter à la file d'attente ».
