Les spécimens resteront dans la file d'attente de crowdsourcing tant que leur statut de traitement ne sera pas passé de « non traité » à un autre état. Utilisez l'éditeur d'occurrences ou l'outil d'édition par lots pour modifier le statut de traitement du ou des spécimens que vous souhaitez retirer de la file d'attente.
