Les instructions générales et les ressources relatives à la géoréférence sont disponibles dans le [Guide de l'éditeur](/Editor_Guide/Georeferencing).

Les gestionnaires de collections (c.-à-d. les utilisateurs disposant de droits d'administrateur) peuvent également transmettre des données au client [GEOLocate Collaborative Georeference](/Collection_Manager_Guide/Georeferencing/collaborative_georeferencing) et utiliser l'outil [Duplicate Data Harvester](/Collection_Manager_Guide/Georeferencing/duplicate_georeferencing) pour récupérer les géoréférences de spécimens en double.
