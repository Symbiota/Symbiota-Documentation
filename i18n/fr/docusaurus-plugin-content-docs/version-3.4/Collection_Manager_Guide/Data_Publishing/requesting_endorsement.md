:::info

**Pour ceux qui publient des données pour la première fois, [demander une validation en tant que diffuseur](https://www.gbif.org/become-a-publisher) est une première étape indispensable du processus de publication.** Cette validation établit votre organisation en tant qu'entité (un « diffuseur ») sur le portail de données du GBIF, permettant ainsi au GBIF d'indexer vos jeux de données comme une contribution de votre université, musée, etc. Ce processus est généralement simple, comme décrit ci-dessous.

:::

| ![Exemple de page de diffuseur GBIF](/img/endorsementpublisherexample.png)                             |
| :--------------------------------------------------------------------------------------------------------------------------: |
| Exemple de page de diffuseur GBIF pour les [ASU Biocollections](https://www.gbif.org/publisher/814cdfb5-d4f8-4453-815f-ea5df98e76bf) |

1. Vérifiez si votre organisation est déjà validée :

- Rendez-vous sur la page [« Devenir diffuseur » du GBIF](https://www.gbif.org/become-a-publisher) et descendez jusqu'en bas de la page. Recherchez attentivement votre institution. Par exemple, une simple recherche sur « ASU » ne fera pas apparaître « Arizona State University » ; essayez donc toutes les combinaisons possibles avant de conclure que votre organisation n'est pas enregistrée. Vous pouvez également rechercher tous les diffuseurs validés sur le portail du GBIF [ici](https://www.gbif.org/publisher/search).
- ⚠️ **Si votre organisation apparaît dans les résultats de recherche, ne demandez pas de validation.** Consultez les coordonnées indiquées sur la page de diffuseur de votre organisation. Si vous n'êtes pas sûr que votre collection doive être publiée en tant que jeu de données rattaché à cette page existante, contactez les personnes indiquées pour obtenir de l'aide avant de poursuivre la publication des données. Vous pouvez également demander conseil au centre d'assistance (Support Hub) si vous ne savez pas quelle marche à suivre.
- **Si votre organisation n'apparaît pas dans les résultats de recherche, passez aux étapes suivantes décrites sur cette page.**

|                                                                                                                                                                                                                                                       ![Example GBIF publisher page](/img/endorsementpublisherexample2.png)                                                                                                                                                                                                                                                       |
| :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------: |
| **Il est possible que votre organisation soit déjà enregistrée en tant qu'éditeur, comme c'est souvent le cas pour les musées et les universités gérant plusieurs collections d'histoire naturelle.** Si vous constatez que votre organisation est déjà enregistrée, contactez la ou les personnes indiquées sur la page éditeur de votre institution pour demander l'ajout de votre collection en tant que jeu de données distinct. Par exemple, les collections biologiques de l'ASU (ASU Biocollections) sont publiées sur le GBIF sous la forme d'une [série de jeux de données](https://www.gbif.org/dataset/search?publishing_org=814cdfb5-d4f8-4453-815f-ea5df98e76bf). |

2. Si ce n'est pas déjà fait, prenez connaissance du contenu de la page du GBIF intitulée « [Devenir éditeur](https://www.gbif.org/become-a-publisher) », qui explique pourquoi la procédure d'approbation est nécessaire.

3. Sélectionnez « Mon organisation n'est pas encore enregistrée », puis consultez et acceptez les conditions générales du GBIF. Une fois cette étape franchie, un formulaire plus détaillé s'affichera.

Pour remplir le formulaire :

4. **_Informations sur l'organisation :_**

- Saisissez les informations relatives à votre organisation. Ces données peuvent être assez proches de celles figurant dans le profil de vos collections sur votre portail Symbiota. Toutefois, si vous sollicitez une approbation pour une organisation hébergeant plusieurs collections susceptibles de publier des données sur le GBIF (actuellement ou ultérieurement), la description doit être plus générale. Consultez, à titre d'exemple, la description figurant sur [la page éditeur des ASU Biocollections](https://www.gbif.org/publisher/814cdfb5-d4f8-4453-815f-ea5df98e76bf).
- Utilisez l'interface cartographique pour placer un repère correspondant à l'emplacement physique de votre organisation.

5. **_Nœud d'approbation :_** Si vous publiez votre jeu de données via un portail Symbiota, sélectionnez « **Symbiota Support Hub** » comme nœud d'approbation si votre collection est située aux États-Unis. **Si votre institution n'est pas basée aux États-Unis**, veuillez contacter [le responsable du nœud GBIF désigné pour votre pays](https://www.gbif.org/the-gbif-network) afin de savoir s'il souhaite valider votre demande. Si votre pays ne dispose pas de nœud, le centre de support Symbiota (Symbiota Support Hub) pourra peut-être vous aider dans cette démarche. Contactez notre [service d'assistance](mailto:help@symbiota.org) si vous avez des questions à ce sujet.

6. **_Projets GBIF :_** Pour la plupart des collections présentes sur les portails Symbiota, la réponse est « **non** ». Répondez « oui » uniquement si vous bénéficiez d'un financement dans le cadre d'un projet BID.

7. **_Contacts :_** **Nous recommandons vivement d'ajouter plusieurs contacts pour votre organisation** et de fournir, si possible, au moins une adresse électronique institutionnelle générique. Cela réduira le risque que la page d'éditeur de votre organisation ne se retrouve sans responsable en raison du renouvellement du personnel.

8. **_Contenu et méthode :_**

- Pour la plupart des collections sur les portails Symbiota, la réponse est « Données d'occurrence uniquement » (Occurrence-only data). Cela désigne les données relatives aux spécimens.
- Dans la section _Description des données_ (Data Description), nous suggérons de saisir un texte tel que :
> Je prévois de publier des occurrences de spécimens via le Consortium of Southern Rocky Mountain Herbaria, un portail Symbiota accessible à l'adresse soroherbaria.org.
- Pour les trois questions restantes, la plupart des collections sur les portails Symbiota devraient sélectionner « **non** ».

9. Sélectionnez « Enregistrer l'organisation » (Register Organization). À ce stade, si vous avez choisi le « Symbiota Support Hub » comme nœud parrain, le GBIF informera ce dernier que votre organisation a demandé une validation en tant qu'éditeur.

10. Une fois validée, votre organisation figurera dans la liste des « Éditeurs validés » (Endorsed Publishers) sur [la page du Participant « Support Hub » sur le site du GBIF](https://www.gbif.org/participant/429). Lorsque vous ouvrirez votre nouvelle page d'éditeur, notez la **clé d'éditeur** (publisher key) qui apparaît dans l'URL de la page ; [utilisez cette clé lorsque vous publierez vos données sur le GBIF (Étape 4)](/Collection_Manager_Guide/Data_Publishing/publishing_gbif).
