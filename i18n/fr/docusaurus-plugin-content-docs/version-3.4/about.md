# Bienvenue sur Symbiota Docs !

:::info
**[Symbiota](https://symbiota.org/)** est un logiciel libre (open-source) de gestion et de mobilisation des données sur la biodiversité, au service de plus de 2 000 collections d'histoire naturelle et de plus de 95 millions d'enregistrements d'occurrences (spécimens ou observations). Consultez **[Symbiota.org](https://symbiota.org/)** pour en savoir plus. Le code source principal de cette version de Symbiota est disponible sur [GitHub](https://github.com/Symbiota/Symbiota).
:::

**[Symbiota Docs](https://symbiota.org/docs)** est un référentiel central pour la documentation relative aux portails de données basés sur Symbiota. Ce site est géré par le *Symbiota Support Hub* (centre de soutien Symbiota), mais tous les utilisateurs de Symbiota peuvent y contribuer. [Contactez-nous](https://symbiota.org/contact-the-support-hub/) pour contribuer ou faire part de vos commentaires sur ce site.

Les portails Symbiota sont utilisés par des milliers de collecteurs, chercheurs, gestionnaires de collections, conservateurs, étudiants, gestionnaires de territoires, éducateurs, et bien d'autres. Symbiota Docs est organisé selon les différents niveaux d'autorisation disponibles pour les utilisateurs des portails Symbiota. Dans le menu de gauche, vous pouvez naviguer entre les guides suivants :

* **[Guide du collecteur/observateur](/Collector_Observer_Guide/)** : Ce guide explique comment les collecteurs de données et/ou de spécimens peuvent ajouter des enregistrements à la collection « Profil d'observations personnelles » d'un portail Symbiota. Les éditeurs de profils d'observations personnelles n'ont pas besoin d'être affiliés à une institution ou une collection spécifique représentée dans le portail.

* **[Guide de l'utilisateur](/User_Guide/)** : Ce guide décrit l'utilisation des outils et fonctionnalités accessibles au grand public. Consultez ce guide si vous souhaitez créer des listes de contrôle (checklists), rechercher ou cartographier des enregistrements, télécharger des données ou utiliser d'autres outils de recherche et d'éducation sur les portails Symbiota.

* **[Guide de l'éditeur](/Editor_Guide/)** : Ce guide contient des instructions pour les utilisateurs disposant de droits d'édition pour une collection sur un site Symbiota. Consultez ce guide si vous souhaitez ajouter, modifier, annoter, géoréférencer ou gérer vos enregistrements au sein d'une collection donnée. * **[Guide du gestionnaire de collection](/Collection_Manager_Guide/)** : Ce guide décrit l'utilisation des outils et fonctionnalités accessibles aux utilisateurs disposant de droits d'administrateur. Consultez ce guide si vous souhaitez modifier des contacts ou des informations concernant votre collection, publier vos données auprès d'autres agrégateurs, nettoyer des données ou accéder à d'autres fonctionnalités réservées aux administrateurs.

* **[Guide du gestionnaire de portail](/Portal_Manager_Guide/)** : Ce guide décrit les fonctionnalités accessibles aux utilisateurs disposant de droits de super-administrateur, telles que l'ajout en masse de noms taxonomiques, la modification du thésaurus géographique et l'importation de déterminations historiques. *Ce guide est en cours d'élaboration.*
