#### Bienvenue dans le guide de l'utilisateur !

Ce guide explique comment utiliser les outils et les fonctionnalités accessibles au grand public. Bien que certaines de ces fonctions nécessitent un compte utilisateur, vous n'avez pas besoin de droits d'éditeur ou d'administrateur pour les utiliser (par exemple, pour créer des listes de contrôle).

Pour savoir comment devenir éditeur de données, consultez notre page [Autorisations des utilisateurs](/User_Guide/user_permissions/).

Pour créer un compte, cliquez sur l'option « Nouveau compte » dans la barre d'outils de n'importe quel portail Symbiota, saisissez les informations demandées, puis cliquez sur « Créer un identifiant ».
