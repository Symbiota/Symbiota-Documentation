Cliquez sur le lien ci-dessous pour consulter la liste des portails Symbiota actifs. Il est conseillé de choisir un portail Symbiota correspondant à la portée de vos données. Vous pouvez intégrer vos données à un portail Symbiota sous forme de collection « en temps réel » (live) ou d'« instantané » (snapshot) ; consultez [cette page](/Collection_Manager_Guide/Joining_Portal/management_types) pour plus d'informations sur les modes de gestion dans les portails Symbiota.

[📇 **Liste des portails Symbiota**](https://symbiota.org/symbiota-portals/)

[📋 **Demande d'adhésion à un portail Symbiota**](https://docs.google.com/forms/d/e/1FAIpQLSf-QywdugIAAxzBLkoKX8er-JkW06Rv4C_Rkm2efPiryTHLGw/viewform)

Une fois que vous avez identifié le portail Symbiota sur lequel vous souhaitez publier vos données de spécimens, contactez les responsables du projet ou du portail pour devenir fournisseur de données. Les coordonnées des responsables figurent généralement sur la page d'accueil ou dans le menu latéral du portail de données. Si vous ne trouvez pas ces informations, veuillez contacter help@symbiota.org pour obtenir de l'aide.

Vous pouvez publier des données sur plusieurs portails ; toutefois, il est recommandé de gérer un jeu de données ou une collection spécifique sur un seul portail Symbiota, les autres portails ne conservant qu'un instantané de ces données. Des collections distinctes (par exemple : plantes vasculaires, lichens ou bryophytes) peuvent être gérées en temps réel sur leurs portails respectifs.

En général, le responsable du portail aura besoin des informations figurant dans la liste ci-dessous pour créer votre collection sur le portail. Une fois la collection ajoutée, les données pourront être chargées. Consultez la page consacrée au [chargement des données de spécimens](/Collection_Manager_Guide/Importing_Uploading) pour plus de détails sur les méthodes et les formats de données acceptés.

**Informations requises pour créer un nouveau profil de collection au sein d'un portail :**

* Titre de la collection tel qu'il apparaîtra sur la page de recherche
* Codes de l'institution et de la collection (par ex. acronymes)
* Brève description du contenu de la collection et des types de préparation
* Contact(s) : nom, fonction, e-mail et identifiant ORCID (si disponible)
* Lien(s) vers la page d'accueil et/ou d'autres ressources externes
* Icône de la collection ou de l'institution : une petite image représentant visuellement la collection (les icônes ayant une hauteur et une largeur sensiblement égales donnent les meilleurs résultats)
* Droits d'utilisation privilégiés. Le gestionnaire du portail devrait pouvoir vous conseiller à ce sujet. Il peut également être utile de consulter les liens Creative Commons suivants : https://creativecommons.org/licenses/, http://wiki.creativecommons.org/Data
* Précision quant au mode de publication : s'agit-il d'un instantané (snapshot) de vos données mis à jour périodiquement, ou prévoyez-vous de gérer les données comme un jeu de données dynamique directement au sein du portail ?
* Source de l'identifiant unique global (GUID) pour les notices de spécimens. Si les notices de spécimens sont gérées directement dans le portail, nous recommandons de laisser le portail générer automatiquement un GUID (UUID) lors de la création des notices. _Si un instantané des données est publié à partir d'un système de gestion de données interne, les GUID doivent être générés localement puis inclus dans les données publiées sur le portail._

**Que faire si je dispose de plusieurs collections ou types de données ?**
Si vous possédez plusieurs collections (par ex. plantes vasculaires, champignons et bryophytes), il est recommandé de les gérer séparément dans leurs portails de données respectifs. En effet, les thésaurus taxonomiques des portails sont soigneusement adaptés au groupe taxonomique qu'ils ciblent ; vous aurez ainsi plus de chances de tirer parti des gains d'efficacité liés à la numérisation (par ex. la détection de doublons) au sein de ce portail. Pour plus d'informations, consultez notre page [Gestion de plusieurs portails](/Collection_Manager_Guide/Joining_Portal/managing_multiple).
