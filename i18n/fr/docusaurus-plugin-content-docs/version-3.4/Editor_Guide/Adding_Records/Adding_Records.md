Il existe plusieurs façons d'ajouter des enregistrements d'occurrence, selon votre niveau d'autorisation. Les éditeurs peuvent ajouter des spécimens sous forme d'enregistrements simplifiés, d'enregistrements complets ou en téléversant une image.
