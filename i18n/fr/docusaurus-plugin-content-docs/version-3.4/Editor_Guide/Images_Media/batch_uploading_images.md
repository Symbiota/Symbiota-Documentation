:::info

Cette page décrit certaines procédures pour le téléversement par lots d'images ou d'autres ressources multimédias vers un portail Symbiota.

:::

Les bases de données Symbiota ne stockent pas physiquement les ressources multimédias (comme les images) ; elles conservent plutôt des liens permettant d'y accéder via le Web. Il existe donc de nombreuses façons d'associer des ressources multimédias aux fiches d'occurrence du portail. Toute solution de stockage capable de fournir une URL accessible sur le Web pour une ressource multimédia peut être utilisée pour associer des images aux occurrences dans un portail Symbiota.

#### Stockage multimédia via le Symbiota Support Hub

Pour les collections disposant de peu de capacités pour héberger leurs propres ressources multimédias, le Symbiota Support Hub (SSH) peut éventuellement héberger des versions prêtes pour le Web (par ex. des fichiers JPEG pour les images) afin qu'elles soient accessibles via un portail Symbiota. Dans ce cas, les ressources multimédias (principalement des images) sont téléversées sur Globus puis transférées vers des serveurs gérés par le SSH. Les URL générées par ces serveurs sont ensuite associées à vos fiches dans le portail Symbiota. Pour savoir si cette option est envisageable pour votre collection, veuillez contacter le [Symbiota Support Hub](mailto:help@symbiota.org).

#### Stockage multimédia via un serveur institutionnel

Si votre établissement a la possibilité de diffuser des ressources multimédias dans un format accessible sur le Web, ces URL peuvent être facilement associées aux occurrences correspondantes dans votre portail grâce à un script de traitement par lots. Contactez l'administrateur de votre portail ou le Symbiota Support Hub pour obtenir plus d'informations ou pour mettre en place cette procédure.
