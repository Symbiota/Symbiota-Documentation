Les caractéristiques (ou « traits ») des occurrences peuvent être renseignées et enregistrées dans certains portails Symbiota (par exemple, le [CCH2](https://cch2.org/portal/), qui contient des données phénologiques pour les plantes vasculaires).

Ces caractéristiques sont stockées dans une table distincte des données principales de l'occurrence ; elles sont consultables dans l'onglet « Traits » de l'éditeur d'occurrence.

Il est souvent possible de télécharger ces caractéristiques en même temps que les données d'occurrence, sous la forme d'un fichier [Extended MeasurementOrFact](https://tools.gbif.org/dwca-validator/extension.do?id=http://rs.iobis.org/obis/terms/ExtendedMeasurementOrFact).

Plusieurs outils ont été développés pour permettre aux utilisateurs d'annoter les fiches de spécimens avec ces caractéristiques, notamment l'outil de [codage des traits à partir d'images](/Editor_Guide/Traits/trait_scoring_images) et l'outil de [codage des traits à partir de texte](/Editor_Guide/Traits/trait_scoring_text). Les caractéristiques disponibles varient selon les portails, et de nouvelles caractéristiques peuvent être créées en fonction des besoins (contactez l'administrateur de votre portail pour plus d'informations).

### Renseigner les caractéristiques d'un spécimen unique

Accédez à l'éditeur d'occurrence pour le spécimen que vous souhaitez documenter (consultez [cette page](/Editor_Guide/Editing_Searching_Records) pour savoir comment trouver des spécimens) et cliquez sur l'onglet « Traits ». Les caractéristiques disponibles pour le codage s'afficheront dans des encadrés au sein de cet onglet. Pour voir des options de codage supplémentaires pour une caractéristique donnée, cliquez sur le triangle noir situé en haut à droite de l'encadré (mis en évidence ci-dessous). Vous pouvez alors renseigner les caractéristiques à partir des images disponibles. Vous avez également la possibilité de supprimer les informations relatives aux caractéristiques en cliquant sur le bouton « Delete Coding » (Supprimer le codage).
