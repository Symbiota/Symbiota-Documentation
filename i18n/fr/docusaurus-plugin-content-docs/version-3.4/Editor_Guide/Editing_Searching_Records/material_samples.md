:::info

Cette page décrit comment ajouter et modifier des enregistrements d'échantillons de matériel associés à des occurrences de spécimens. Un échantillon de matériel est généralement considéré comme un sous-échantillon d'une occurrence.

:::

:::note

L'onglet « Échantillon de matériel » (Material Sample) ne sera visible que s'il a été activé pour votre collection. Contactez le gestionnaire de votre portail pour savoir si cet onglet a été configuré pour votre portail Symbiota.

:::

## Champs de données pour les échantillons de matériel

Les définitions des champs de données affichés dans l'onglet « Échantillon de matériel » se trouvent dans la documentation relative aux [champs de données Symbiota](/Editor_Guide/Editing_Searching_Records/symbiota_data_fields#material-sample-fields).

## Ajout/Modification d'enregistrements d'échantillons de matériel

:::note

Une occurrence de spécimen dans un portail Symbiota peut être associée à un ou plusieurs échantillons de matériel.

:::

### Ajout d'échantillons de matériel individuels

| ![Exemple d'échantillon de matériel](/img/materialsampleeditor2026.png)                                                                                                         |
| :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------: |
| Occurrence de spécimen avec plusieurs enregistrements d'échantillons de matériel associés, telle qu'elle apparaît dans l'éditeur d'occurrences. [Cet exemple](https://biorepo.neonscience.org/portal/collections/individual/index.php?occid=277316) provient du portail Symbiota de la biobanque NEON (NEON Biorepository). |

**Pour ajouter un nouvel échantillon de matériel à un enregistrement de catalogue existant :**

1. Accédez à l'éditeur d'occurrences : _cliquez sur « Mon profil » (My Profile), puis sur le nom de la collection dans le bloc « Gestion des collections » (Collection Management)_.
2. [Recherchez](/Editor_Guide/Editing_Searching_Records) l'enregistrement auquel l'échantillon sera associé. Ouvrez l'enregistrement pour afficher le formulaire de l'éditeur d'occurrences.
3. En haut du formulaire, sélectionnez l'onglet « Échantillon de matériel » (Material Sample).
4. Cliquez sur l'icône « plus » (+) pour commencer à ajouter un nouvel échantillon de matériel. 5. Pendant que vous remplissez le formulaire, consultez les [définitions Symbiota pour les champs de données relatifs aux échantillons de matériel](/Editor_Guide/Editing_Searching_Records/symbiota_data_fields#material-sample-fields) si vous n'êtes pas familier avec ces termes.
6. Cliquez sur le bouton « Ajouter un enregistrement » pour enregistrer la nouvelle fiche d'échantillon de matériel.
7. Répétez l'opération, en commençant à l'étape 4, pour ajouter d'autres fiches d'échantillons de matériel.

:::tip

Pour **modifier** des fiches d'échantillons de matériel existantes, accédez à l'onglet « Material Sample » (Échantillon de matériel) et cliquez sur l'icône en forme de crayon pour rouvrir le formulaire modifiable.

:::

### Ajout en masse d'échantillons de matériel

Les fiches d'échantillons de matériel peuvent être importées en masse à l'aide des outils d'importation de données étendues (Extended Data Import) situés dans le panneau de configuration de l'administrateur. Consultez [cette page](/Collection_Manager_Guide/Importing_Uploading/material_samples) pour obtenir des instructions.

### Téléchargement des échantillons de matériel

Les données saisies dans l'onglet « Material Sample » peuvent être [téléchargées](/Editor_Guide/Downloading_Data/downloading_darwin_core_archive) depuis Symbiota sous forme d'archive Darwin Core ou de fichier de sauvegarde de données Symbiota. Le fichier généré sera nommé _materialSample.csv_.
