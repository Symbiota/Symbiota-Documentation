:::info

Cette page explique comment imprimer des étiquettes d'annotation dans un portail Symbiota.

:::

Pour utiliser cet outil, vous devez d'abord ajouter les spécimens annotés à la file d'attente d'impression des annotations. Cette opération peut être effectuée individuellement, via l'éditeur d'occurrences, ou par lots à l'aide de l'outil « Ajouter des déterminations/ajustements nomenclaturaux par lots » (voir [Annotations/Déterminations](/Editor_Guide/Editing_Searching_Records/annotations) pour les instructions).

Pour imprimer des étiquettes d'annotation, accédez au panneau de configuration de l'éditeur de données (_cliquez sur « Mon profil », puis sur le nom de la collection dans le bloc « Gestion des collections »_) et cliquez sur « Imprimer les étiquettes d'annotation ». Un tableau s'affiche, listant tous les spécimens présents dans la file d'attente d'impression des annotations. Cochez les cases situées dans la colonne de gauche, en regard des notices de spécimens pour lesquelles vous souhaitez imprimer des annotations.

![Impression d'annotations](/img/annotationprinting2026.png)

Pour consulter la notice d'un spécimen, cliquez soit sur le nom et le numéro du collecteur (pour afficher la notice publique), soit sur l'icône en forme de crayon située à côté de ces informations (pour accéder à l'éditeur d'occurrences correspondant).

Personnalisez votre étiquette d'annotation à l'aide des options proposées, puis choisissez « Imprimer dans le navigateur » ou « Exporter au format DOCX » (pour obtenir un document Microsoft Word).

Cochez la case « Supprimer les annotations sélectionnées de la file d'attente » si vous souhaitez retirer ces spécimens de la file d'attente après avoir cliqué sur l'un des boutons d'impression.
